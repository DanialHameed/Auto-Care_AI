# AutoCare AI

**AutoCare AI** is an evidence-grounded vehicle diagnostic, repair-verification, and maintenance-prediction system. It helps users identify vehicle issues, verify completed repairs, and predict upcoming maintenance needs — grounding every output in evidence rather than generic guesswork. The system supports **English, Urdu, and Roman Urdu**, making reliable vehicle care accessible across language preferences.

This is a final-year project (FYP) developed at the **Punjab University College of Information Technology (PUCIT)**, University of the Punjab, under the supervision of **Dr. Khurram Shehzad**, Department of Data Science.

## Features
- Evidence-grounded vehicle fault diagnosis
- Repair verification against reported issues
- Predictive maintenance scheduling
- Multilingual support (English, Urdu, Roman Urdu)
